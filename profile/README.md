<h2>一、iOS 能改的地方比想象中少</h2>
<p>系统设置里没有全局代理开关。能直接配的只有当前 Wi-Fi 连接，换一个网络就要重配。</p>
<p>装描述文件可以做到全局，但需要信任证书，操作步骤多，普通用户容易在中途放弃。</p>

<h2>二、Wi-Fi 手动代理：最直接的一种</h2>
<p>进入无线局域网，点当前网络右侧的信息按钮，拉到底部找到配置代理，改成手动。</p>
<p>填服务器地址和端口，需要认证时打开身份验证，填用户名和密码，保存后立即生效。</p>
<p>切换 Wi-Fi 或重连后设置会保留在该网络下，换到别的网络就失效，这点要记住。</p>
<h3>地址不要带协议前缀</h3>
<p>iOS 的这两个输入框只填主机和端口，写 http 或 socks5 前缀会直接连不上，这是最常见的错误。</p>
<h2>三、需要全局时怎么办</h2>
<p>全局方案一般走描述文件或客户端。描述文件装完后在设置里能看到，删除也在同一位置。</p>
<p>安装描述文件会要求输入锁屏密码，并在关于本机里出现证书信任项，装完记得检查是否已信任。</p>
<p>全局方案的代价是所有流量都走代理，包括系统更新和推送，流量消耗会明显增加。</p>
<h2>四、验证是否生效</h2>
<p>用 Safari 打开显示 IP 的页面，看城市与运营商。Safari 走系统网络栈，结果最能代表整机状态。</p>
<p>再看 DNS。iOS 的解析行为与 Wi-Fi 设置相关，代理没接管解析时，位置判断仍可能出错。</p>
<p>最后开一个需要登录的应用，走一遍完整流程，看是否有额外的验证提示。</p>

<h2>五、蜂窝网络下的限制</h2>
<p>Wi-Fi 代理设置不作用于蜂窝数据。切到 4G 或 5G 后，流量直接走运营商，出口立刻变回本地。</p>
<p>想在蜂窝下也走代理，只能用描述文件或客户端，且要确认它支持蜂窝网络。</p>
<p>双卡机型要注意当前数据卡是哪一张，配错卡等于没配，这一点在排查时最容易被忽略。</p>
<p>副卡如果只做短信接收，不必配代理。让数据流量走主卡，配置和排查都会简单一些。</p>
<h3>关掉无线局域网助理</h3>
<p>这个功能会在 Wi-Fi 信号弱时自动切到蜂窝，代理随之失效。固定环境使用时建议关闭。</p>
<h2>六、常见失败与处理</h2>
<p>一是填了前缀导致连不上，去掉 http 或 socks5 再试。</p>
<p>二是密码里有特殊字符，iOS 不会提示，改用简单密码或换认证方式验证一次。</p>
<p>三是描述文件装了没信任，去关于本机的证书信任设置里打开开关。</p>
<p>四是旧连接还在复用，开关一次飞行模式，让网络栈重新建立连接。</p>
<h3>怎么干净地切回自动</h3>
<p>Wi-Fi 里把配置代理改回自动或关闭；描述文件在已下载描述文件里移除；客户端直接退出并删除。三步都做完才算干净。</p>
<h2>常见问答</h2>
<h3>iPhone 能设全局代理吗？</h3>
<p>答：系统设置里只能给单个 Wi-Fi 配代理。要全局生效需要安装描述文件或使用专用客户端。</p>
<h3>为什么填了地址还是连不上？</h3>
<p>答：先检查有没有多写协议前缀。iOS 的输入框只接受主机和端口，带前缀会被当成域名解析而失败。</p>
<h3>切到流量后代理就失效了，正常吗？</h3>
<p>答：正常。Wi-Fi 代理只作用于该无线网络，蜂窝数据不走这个设置。</p>
<h3>描述文件和客户端哪个更省事？</h3>
<p>答：客户端安装和切换更简单，描述文件更贴近系统层。按使用频率选，长期固定环境用描述文件。</p>
